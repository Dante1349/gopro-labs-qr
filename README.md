# gopro-labs-qr

Phone scan page for Marc’s Mission 1 Pro Labs presets.

**Live:** https://dante1349.github.io/gopro-labs-qr/

Source of truth: `~/.cursor/skills/video-editing/labs-qr/setup.html` in private `cursor-config`. After regenerating QRs, `generate_qrs.py` copies `index.html` here — then push this repo.

This repo is public because GitHub Free cannot host Pages from a private repo. The page is `noindex` and only contains Labs QR commands (no skills, no personal data).
